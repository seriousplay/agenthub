## 怎么打开

直接用浏览器打开本目录里的 `index.html` 即可，不必起服务器：

- macOS：在 Finder 中双击，或把文件拖进 Chrome / Safari / Firefox
- 也可在地址栏进入 `file://` 路径，例如  
  `file:///workspace/zhuzi-game-view-20261117/index.html`

本页不依赖网络，没有 npm / 构建步骤，也不加载外部 CDN。若浏览器允许读取同目录的 `snapshot.json`，会优先用文件里的数据；`file://` 下常会失败，此时自动改用页面内嵌的同一份快照，内容一致。

页脚有一个低调的「载入快照」，可选择另一份结构相同的 `snapshot.json` 做本地回放。

## 什么是真实的，什么是回放

真实（全部来自 `snapshot.json`，本仪没有编造任务、客户名、状态或分数）：

- 十位伙伴的姓名、职司、状态、当前句、详情和工作线关联（证据时间仍为原 07:43 快照）
- 另附 Codex（外部编码智能体，状态为验收未完成，最后记录 2026-11-11 08:12）与 Hermes（职司与当前任务均未核实，无最后更新日期）
- 六条工作线及其状态与说明
- 六条来件
- 管线计数：已核实 6、进行中 1、等待义情 3、近期已交 3、验收未完成 1、未核实 6。验收未完成不计当前进行中
- 快照时间、包更新时间与诚实声明

回放（为了让仪器「在拍上动起来」而做的编排，不是实时接口）：

- 把上述来件、智能体、工作线排成回放拍，约 1.6 秒一拍，循环播放
- 转盘指针、织机纬线、传送带包裹、牌面、节拍音符、蜂群位置，都是对这些事实的可视化
- 「连击」只表示连续若干拍属于已核实状态，不是游戏分数
- 未核实者（鲁班、老子、孙子、公孙龙、范蠡、Hermes）只有暗淡的「未核实」拍，不会被画成正在干活或空闲待命
- Codex 不伪装为 Grok Bot 伙伴，也不标成进行中

这不是 live 的 LoopOS / Grok Bot 控制面，没有派发、停止或批准操作。

## 如何点选 Codex / Hermes

先按空格键暂停，避免拍在跳。然后任选一种方式锁定：

- 牌桌：底端扇形牌从左到右为原十位，最后两张是 Codex 与 Hermes，直接点牌
- 转盘：右侧弧上点对应扇区（Codex、Hermes 在原十位之后）
- 蜂群：Codex 在 LoopOS 花附近；Hermes 在底部「未在共享场合核实」栏，与鲁班等并列

锁定后详情卡显示完整说明；Codex / Hermes 的证据为可点击的普通链接。再点一次或按「清除锁定」恢复全表回放。

## 六个视图

1. **转盘** — 十位智能体沿精密刻度弧排列，指针指到当前拍的人；右侧仪表罐显示管线计数。
2. **织机** — 六条工作线作经线，每一拍织入一纬；布面会增长，循环处有淡分隔。
3. **流水线** — 等轴传送带与机械臂；拍落时放下真实的来件 / 任务 / 工作线包裹，已交件可在末端打开，未核实为密封暗盒。
4. **牌桌** — 底端十张智能体牌，当前拍打出中心牌；计分板只显示拍号与真实计数，没有虚构得分。
5. **节拍** — 六条工作线车道，音符落向弧形判定梁；判定词用状态（进行中 / 等待 / 已交 / 未核实），不用 PERFECT。
6. **蜂群** — 巢为诸子百家，花为六条工作线。墨子在任务仪旁工作，等待者徘徊在自己的工作线旁，未核实者安静待在边缘。

顶部可随时切换视图，共用同一套回放时钟。点击智能体（扇区、牌、蜜蜂等）会锁定并只回放与其相关的拍；再次点击或按「清除锁定」恢复。空格键暂停 / 继续，方向键单步，数字 1–6 切换视图。
